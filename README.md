# neutralinojs-minimal

The default template for a Neutralinojs app. It's possible to use your favorite frontend framework by using [these steps](https://neutralino.js.org/docs/getting-started/using-frontend-libraries).

## Getting Started

To run or build this project, you need to follow these steps:

1. **Install Neutralino CLI** (if you haven't already):
   ```bash
   npm install -g @neutralinojs/neu
   ```
2. **Initialize and Update**:
  After cloning the repository, you must run the following command to download the Neutralinojs binaries and the client library (neutralino.js):
   ```bash
   neu update
   ```
3. **Run the Application**:
   ```bash
   neu run
   ```
4. **Build for Distribution:**:
   ```bash
   neu build
   ```
